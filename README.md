# 단계별 학습실

모바일 화면과 관리자 이력 조회를 갖춘 Python·SQLite 학습 프로토타입입니다. 공개본에는 가상 예제 3문항이 들어 있습니다.

```powershell
py -3 app.py
```

http://127.0.0.1:8765 에 접속합니다. 처음 실행하면 터미널에 초기 관리자 아이디 `admin`의 비밀번호가 표시됩니다. 관리자 화면에서 연습용 학습자 계정을 생성할 수 있습니다.

비공개 콘텐츠가 필요한 운영 환경은 별도로 보관하세요. SQLite, 세션, 운영 설정 및 비공개 문항·근거 파일은 이 공개 저장소의 등록 대상에서 제외합니다.
